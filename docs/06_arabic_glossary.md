# 06. Arabic glossary (financial statement labels)

Map Arabic labels to standard fields. Companies use variants; when a new variant appears, it is added here once confirmed. No label is mapped by guesswork.

## Statements and documents

| English | Arabic (common variants) |
| --- | --- |
| Financial statements | القوائم المالية |
| Consolidated | المجمعة |
| Separate / standalone | المستقلة / الدورية المستقلة |
| Income statement | قائمة الدخل / قائمة الأرباح أو الخسائر |
| Statement of comprehensive income | قائمة الدخل الشامل |
| Balance sheet | قائمة المركز المالي |
| Cash flow statement | قائمة التدفقات النقدية |
| Statement of changes in equity | قائمة التغير في حقوق الملكية |
| Notes to the financial statements | الإيضاحات المتممة للقوائم المالية |
| Auditor's report | تقرير مراقب الحسابات |
| Qualified opinion | رأي متحفظ |
| Going concern | الاستمرارية |
| In EGP thousands | بالألف جنيه مصري (check header for units) |
